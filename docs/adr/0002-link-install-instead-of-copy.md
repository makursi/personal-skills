# 用目录链接安装，不用复制

决定安装方式是目录链接：Windows 上用 junction，其他平台用目录符号链接。消费目录里的每一项都指回仓库中的对应目录。

## Considered Options

- **复制**：消费目录自包含，能脱离仓库单独存在。否决理由：改完必须重新复制，一旦忘记就出现两个版本，回到“唯一真源”之前的处境。
- **登记进第三方安装器的 lock 文件**：由同一个管理器统管。否决理由：管理器会按内容哈希覆盖消费目录，手写内容会被冲掉。

## Consequences

- 仓库被移动或删除时，消费目录里的链接失效，需要重新安装。
- 链接不需要管理员权限。消费目录已存在真实目录时，安装器拒绝覆盖，除非显式加 `--force`。
